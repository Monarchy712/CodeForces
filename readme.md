# Codeforces Solutions

My accepted solutions to [Codeforces](https://codeforces.com) problems.

**Handle:** [YOUR_HANDLE](https://codeforces.com/profile/YOUR_HANDLE)

## Conventions

- One file per problem, named `<problemID>_<slug>.cpp`
- Every file starts with a header comment: problem link, rating, tags, and a one-line note on the approach
- Only accepted submissions get committed

Example header:

```cpp
// 231A - Team
// https://codeforces.com/problemset/problem/231/A
// Rating: 800 | Tags: brute force, greedy
// Count rows where at least 2 of 3 are confident.
```

## Compiling

```bash
g++ -std=c++17 -O2 -Wall -o sol 231A_team.cpp
./sol < input.txt
```

## Why this repo exists

Practice log, not a solution bank. Reading someone else's code teaches you much less than sitting with the problem for another twenty minutes. Use these to compare approaches *after* you've solved it.
